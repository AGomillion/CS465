# CS465
In this module, I initiated the development of the Travlr Getaways full stack application utilizing the MEAN stack. Adhering to the Module One Full Stack Guide and the project rubric, I successfully completed the initial configuration of the Node.js server, set up Express, and confirmed that the static HTML pages for Travlr Getaways are rendered accurately in the browser.

Cloning the Repository and Establishing the Module1 Branch
Initially, I cloned my GitHub repository onto my local development machine and established a specific module1 branch. This practice ensures that all activities related to Module One are kept separate, traceable, and in accordance with best practices for version control. Additionally, I modified the .gitignore file to exclude Node modules and other generated files, thereby maintaining a clean repository and preventing the inclusion of unnecessary files in commits.

Constructing the Express Server and Website Framework
To fulfill the rubric's requirement of developing a website using Node.js and Express, I initialized a Node project and installed Express as the main web framework. Express offers the necessary structure to serve static content and will later facilitate the integration of dynamic JavaScript logic as the application progresses.

I created a public directory within the project folder and placed the HTML mockup files for Travlr Getaways into this directory. This organization adheres to Express conventions, where the public folder is designated for serving static assets such as HTML, CSS, and images.

Delivering Static HTML Content
I configured the Express server to serve static content from the public folder. This configuration enables the Travlr Getaways mockup pages to be displayed directly in the browser when the appropriate URL is accessed. This step illustrates that the server is operating correctly and that the static content is situated in the correct location within the Express framework.
